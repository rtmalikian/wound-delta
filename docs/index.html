⚠️ PROOF OF CONCEPT — NOT CLINICALLY TESTED

This tool has not been tested clinically and is a proof-of-concept for research and software demonstration only. It is not a medical device, it does not diagnose, treat, or rule out any condition, and its outputs may be wrong — including false positives and false negatives.

Do not use it to make decisions about your health. For any medical issue or concern, seek a licensed healthcare professional. In an emergency, go to your nearest emergency room or dial 911 immediately.

DEMO DATA

WoundDelta

Wound-change measurement, not diagnosis: ghost-overlay re-photography, align-and-diff in code.

Static GitHub Pages preview. No backend and no AI model are connected — everything below runs in your browser on pretend data and shows sample outputs only. The real tool is open source and self-hostable: github.com/rtmalikian/wound-delta

Try the mini-demo

Pretend visit measurements. The real tool aligns two photos and diffs them in code — unchanged pairs cost zero model calls; only the changed crop is ever sent.

Run the real thing (self-hosted)

Clone the repo and start it with Docker Compose — it ships with an embedded OpenAI-compatible gateway (stub / local model / any OpenAI-compatible upstream), so PHI never has to leave your machine:

git clone https://github.com/rtmalikian/wound-delta
cd wound-delta
docker compose up
